# MCPL — 고전 마인크래프트 미니게임 리마스터

예전에 마인크래프트 방송에서 유행하던 고전 콘텐츠(초능력전쟁, 랜덤무기전쟁, 살인자를 찾아라 …)를
**최신 버전(Paper 26.3)** 에 맞게 다시 만든 플러그인입니다.
플러그인 하나에 여러 미니게임이 들어 있어서, 플러그인을 바꾸지 않고도 명령어 한 줄로 모드를 고르거나 **순환 플레이**할 수 있습니다.
방송인뿐 아니라 친구들끼리 서버에서 바로 즐길 수 있도록 만들었습니다.

| 모드 | 상태 |
|---|---|
| **초능력전쟁** — 24가지 초능력으로 싸우는 최후의 1인(팀) 생존전 | ✅ 플레이 가능 |
| 랜덤무기전쟁 | 예정 |
| 살인자를 찾아라 | 예정 |

## 특징

- **설치 즉시 플레이**: jar를 넣고 `/게임 시작 초능력전쟁`만 입력하면 됩니다. 전용 맵 없이 지금 있는 월드에서 진행됩니다.
- **원상 복구**: 경기 전에 모든 참가자의 인벤토리, 위치, 체력, 경험치, 효과, 게임모드를 저장해 두었다가 경기 후 그대로 돌려놓습니다.
  서버가 꺼지거나 플레이어가 나가도 다음 접속 때 복구됩니다.
- **월드 보호**: 경기 중에는 블록 파괴, 블록 설치, 폭발, 불 번짐, 문·상자 상호작용을 막습니다.
  능력이 만드는 얼음 감옥, 바위 벽 같은 블록은 모두 임시 블록이라 자동으로 사라집니다.
- **보는 재미**:
  - 경기 중에는 능력 공개 슬롯머신 연출, 궁극기 전체 공지, 능력 이름이 붙은 킬로그가 나옵니다.
  - 자기장 보스바, 사이드바, 파티클과 디스플레이 엔티티 이펙트로 상황이 한눈에 보입니다.
  - 경기가 끝나면 우승 폭죽과 결산(순위, 킬, 피해량, MVP)이 나옵니다.
- **개인전 / 팀전**, **순환 모드**를 지원하고 모든 수치를 설정할 수 있습니다.

## 설치

1. **Paper 26.3** 서버를 준비합니다. Java 25가 필요합니다.
2. [Releases](https://github.com/sx2xoox/MC-PL/releases) 또는 직접 빌드한 `MC-PL-<버전>.jar`를 `plugins/` 폴더에 넣습니다.
3. 서버를 켜면 `plugins/MCPL/` 폴더에 아래 파일이 생깁니다.
   - `config.yml`: 허브와 각 게임 설정
   - `abilities.yml`: 초능력별 사용 여부와 수치
   - `messages.yml`, `superpower.yml`: 메시지

### 직접 빌드

```bash
./gradlew build          # build/libs/MC-PL-<버전>.jar
./gradlew runServer      # 플러그인이 설치된 Paper 26.3 테스트 서버 실행
```

## 빠른 시작

```
/게임 시작 초능력전쟁      # 접속 중인 모두가 참가 (관전하려면 미리 /게임 관전)
/게임 중지                # 경기 강제 종료 + 모두 복구
/게임 순환 켜기           # 경기가 끝나면 다음 게임 자동 시작
```

## 초능력전쟁

1. **카운트다운**: 카운트다운이 끝나면 모두 경기장(기본: 시작한 사람의 위치, 반경 60)에 흩어져 기본 킷을 받습니다. 기본 킷은 철 갑옷, 철검, 음식입니다.
2. **능력 공개**: 슬롯머신 연출로 각자의 능력이 공개됩니다. 공개 후 **15초 준비 시간** 동안은 무적이며, 웅크리고 능력 아이템을 우클릭하면 **리롤 1회**를 쓸 수 있습니다.
3. **전투**: 2분 뒤부터 **자기장**이 줄어들고, 자기장 바깥에서는 계속 피해를 받습니다.
4. **승리**: 마지막까지 살아남은 1명(팀전은 1팀)이 승리합니다.

### 조작

| 입력 | 동작 |
|---|---|
| 능력 아이템(핫바 9번)을 들고 **우클릭** | 액티브 스킬 (쿨타임은 아이템에 표시) |
| **F** (손 바꾸기) | 궁극기 (경험치 바의 게이지가 100%일 때) |
| 준비 시간에 **웅크리고 우클릭** | 능력 리롤 |

궁극기 게이지는 적에게 준 피해, 받은 피해, 그리고 시간 경과로 충전됩니다.

### 능력 24종

| 계열 | 능력 |
|---|---|
| 원소 | 화염술사 · 뇌신 · 빙결술사 · 바람술사 |
| 기동 · 암살 | 순간이동자 · 그림자 · 갈고리술사 · 시간술사 |
| 근접 · 탱커 | 광전사 · 거인 · 수호자 · 흡혈귀 |
| 제어 | 중력술사 · 대지술사 · 독술사 · 거울술사 |
| 원거리 · 소환 · 지원 | 궁수 · 폭탄마 · 소환사 · 치유사 |
| 특수 | 요정 · 불사조 · 환영술사 · 도박사 |

각 능력의 패시브, 액티브, 궁극기 설명은 게임 안에서 `/게임 능력 목록`, `/게임 능력 정보 <능력>`으로 확인하거나
[docs/superpower.md](docs/superpower.md)에서 볼 수 있습니다.

## 명령어

루트 명령어는 `/게임`입니다. 별칭은 `/mcpl`, `/mg`이며, 모든 하위 명령어에 영어 이름도 있습니다.

| 명령어 | 권한 | 설명 |
|---|---|---|
| `/게임 시작 [모드]` (`start`) | 관리자 | 경기 시작. 모드를 생략하면 순환 목록의 다음 모드 |
| `/게임 중지` (`stop`) | 관리자 | 경기 강제 종료 및 복구 |
| `/게임 목록` (`list`) | 모두 | 미니게임 목록 |
| `/게임 참가` / `/게임 관전` (`join` / `spectate`) | 모두 | 다음 경기 참가 / 관전 선택 |
| `/게임 순환 켜기·끄기·목록` (`rotation`) | 관리자 | 순환 모드 |
| `/게임 경기장 설정 [반경]` / `초기화` (`arena`) | 관리자 | 현재 위치를 경기장 중심으로 저장 / 해제 |
| `/게임 설정 팀 <팀당 인원>` (`settings team`) | 관리자 | 0 = 개인전 |
| `/게임 리로드` (`reload`) | 관리자 | 설정 다시 불러오기 |
| `/게임 능력 목록` · `정보 <능력>` (`ability list/info`) | 모두 | 능력 설명 |
| `/게임 능력 리롤` (`ability reroll`) | 모두 | 준비 시간 중 리롤 |
| `/게임 능력 지정 <플레이어> <능력>` (`ability assign`) | 관리자 | 다음 경기 능력 지정 (방송 연출용) |
| `/게임 능력 선택방식 <RANDOM/CHOICE>` (`ability mode`) | 관리자 | 랜덤 배정 / 후보 3개 중 선택 |
| `/게임 능력 연습 [능력]` · `변경 <능력>` · `충전` · `쿨타임 <켜기/끄기>` · `허수아비 [개수]` (`ability practice/switch/charge/cooldown/dummies`) | 시작·쿨타임은 관리자, 나머지는 모두 | 혼자서 훈련용 허수아비로 능력 연습 (피해량 숫자 표시, 죽어도 부활, `/게임 중지`로 종료). `/게임 시작 연습`은 모두 참가 |

권한은 두 가지입니다.
- `mcpl.admin`: 관리자 명령어. 기본값은 OP입니다.
- `mcpl.play`: 참가와 정보 확인. 기본값은 모두입니다.

## 설정

- **`config.yml`**: 아래 항목에 모두 한국어 주석이 달려 있습니다.
  - 허브 설정: 순환 목록과 대기 시간, 경기장, 카운트다운, 팀 인원, 월드 보호 항목
  - 초능력전쟁 설정(`games.superpower`): 능력 배정 방식, 리롤 횟수, 준비 시간, 제한 시간, 기본 킷, 궁극기 게이지 충전량, 자기장 타이밍, 파티클 양 배율
- **`abilities.yml`**: 능력마다 `enabled`(사용 여부)와 쿨타임, 피해량, 범위 같은 모든 수치를 조정할 수 있습니다.
- 수정한 뒤 `/게임 리로드`를 입력하면 다음 경기부터 적용됩니다.

## 개발

- 구조와 규칙은 [CLAUDE.md](CLAUDE.md)를, 게임 규칙은 [docs/](docs/)를 참고하세요.
- 새 미니게임을 추가할 때는 `core.game.MiniGame`을 구현해 `MCPLPlugin#registerGames`에서 등록합니다.
- 새 능력을 추가할 때는 `Ability`를 상속해 `BuiltinAbilities`에 등록합니다.
