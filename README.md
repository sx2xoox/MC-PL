# MCPL — 고전 마인크래프트 미니게임 리마스터

예전에 마인크래프트 방송에서 유행하던 고전 콘텐츠(초능력전쟁, 랜덤무기전쟁, 살인자를 찾아라 …)를
**최신 버전(Paper 26.3)** 에 맞게 다시 만든 플러그인입니다.
플러그인 하나에 여러 미니게임이 들어 있어서, 플러그인을 바꾸지 않고도 명령어 한 줄로 모드를 고르거나 **순환 플레이**할 수 있습니다.
방송인뿐 아니라 친구들끼리 서버에서 바로 즐길 수 있도록 만들었습니다.

| 모드 | 상태 |
|---|---|
| **초능력전쟁** — 151가지 초능력으로 싸우는 최후의 1인(팀) 생존전 | ✅ 플레이 가능 |
| **증강 야생전** — 경기마다 새 야생 월드에서 파밍 후 PvP, 시간마다·업적마다 증강 카드 3장 중 하나를 고르는 생존전 | ✅ 플레이 가능 |
| 랜덤무기전쟁 | 예정 |
| 살인자를 찾아라 | 예정 |

## 특징

- **설치 즉시 플레이**: jar를 넣고 `/게임 시작 초능력전쟁`만 입력하면 됩니다. 전용 맵 없이 지금 있는 월드에서 진행됩니다.
- **전투용 맵 내장**: `/게임 경기장 맵 citadel` 한 줄이면 지름 약 210블록의 전투 맵 **폐허의 성채**를 전용 월드에 지어 경기장으로 씁니다.
  기존 월드는 건드리지 않습니다.
- **원상 복구**: 경기 전에 모든 참가자의 인벤토리, 위치, 체력, 경험치, 효과, 게임모드를 저장해 두었다가 경기 후 그대로 돌려놓습니다.
  서버가 꺼지거나 플레이어가 나가도 다음 접속 때 복구됩니다.
- **월드 보호**: 경기 중에는 블록 파괴, 블록 설치, 폭발, 불 번짐, 문·상자 상호작용을 막습니다.
  능력이 만드는 얼음 감옥, 바위 벽 같은 블록은 모두 임시 블록이라 자동으로 사라집니다.
- **부서지는 전장**: 전투 맵에서는 폭발과 강타 같은 능력이 엄폐물을 무너뜨리고 땅에 얕은 구덩이를 내서 경기가 진행될수록
  전장이 망가집니다. 부서진 블록은 경기가 끝나면 한꺼번에 원래대로 돌아오고, 아이템은 떨어지지 않습니다.
- **보는 재미**:
  - 경기 중에는 능력 공개 슬롯머신 연출, 궁극기 전체 공지, 능력 이름이 붙은 킬로그가 나옵니다.
  - 자기장 보스바, 사이드바, 파티클과 디스플레이 엔티티 이펙트로 상황이 한눈에 보입니다.
  - 경기가 끝나면 우승 폭죽과 결산(순위, 킬, 피해량, MVP)이 나옵니다.
- **보급 상자**: 전투가 시작되면 경기장 곳곳에 상자가 나타나고, 자기장이 줄어들기 시작하면 하늘에서 보급 상자가 떨어집니다.
  황금 사과, 엔더 진주, 물약 같은 소소한 아이템과 가끔 다이아몬드 장비, 초능력 전용 아이템(궁극기 결정, 재충전 부적)이 들어 있습니다.
- **낮과 밤, 비**: 전투 맵에서는 정오에 시작해 자기장이 줄어드는 동안 노을이 지고, 마지막 싸움은 밤에 벌어집니다. 세 판에 한 판꼴로
  싸우는 도중 1~2분 동안 비가 내립니다(천둥·번개 없음). 늑대인간·천문학자·팬텀·빛의 사도는 밤낮을, 수류술사·낚시꾼·갓파는 비를
  탑니다. 경기가 끝나면 맵은 다시 정오·맑음으로 돌아오고, 일반 월드의 시간과 날씨는 건드리지 않습니다.
- **경기마다 새 야생 월드** (증강 야생전): 무작위 시드의 바닐라 월드를 만들어(청크는 미리, 서버가 버벅이지 않게 조금씩)
  20분 파밍 → PvP와 좁아지는 월드보더로 이어지고, 경기가 끝나면 월드를 통째로 지웁니다. 서버가 꺼져 남은 월드도 다음 시작 때 지웁니다.
- **증강**: 롤 무작위 총력전·롤토체스처럼 정해진 시간마다 모두가 같은 등급(실버·골드·프리즘)의 증강 카드 3장 중 하나를 고르고(리롤 2회),
  첫 번째 피·심연의 광부·기적의 착지 같은 특별한 업적을 달성하면 증강을 하나 더 받습니다.
- **개인전 / 팀전**, **순환 모드**를 지원하고 모든 수치를 설정할 수 있습니다.
  팀전에서는 팀원끼리 서로의 능력을 사이드바와 채팅으로 볼 수 있습니다.
- **게임 안에서 설정**: `/게임 설정`을 입력하면 설정 메뉴(상자 화면)가 열립니다. 팀 인원, 상자, 자기장, 준비 시간 같은 값을
  클릭으로 바꾸면 `config.yml`에 바로 저장되고(주석은 그대로) 다음 경기부터 적용됩니다. 같은 일을 명령어로도 할 수 있습니다.

## 설치

1. **Paper 26.3** 서버를 준비합니다. Java 25가 필요합니다.
2. [Releases](https://github.com/sx2xoox/MC-PL/releases) 또는 직접 빌드한 `MC-PL-<버전>.jar`를 `plugins/` 폴더에 넣습니다.
3. 서버를 켜면 `plugins/MCPL/` 폴더에 아래 파일이 생깁니다.
   - `config.yml`: 허브와 각 게임 설정
   - `abilities.yml`: 초능력별 사용 여부와 수치
   - `augments.yml`: 증강과 보너스 조건별 사용 여부, 등급, 수치
   - `messages.yml`, `superpower.yml`, `augment.yml`: 메시지
   - `augment-bots-chat.yml`: 봇전·봇 관전전에서 봇이 채팅으로 하는 말 (상황·성격별 문구)

### 직접 빌드

```bash
./gradlew build          # build/libs/MC-PL-<버전>.jar
./gradlew runServer      # 플러그인이 설치된 Paper 26.3 테스트 서버 실행
```

## 빠른 시작

```
/게임 시작 초능력전쟁      # 접속 중인 모두가 참가 (관전하려면 미리 /게임 관전)
/게임 시작 증강           # 증강 야생전: 새 야생 월드에서 파밍 → PvP
/게임 증강 연습           # 증강 연습: 혼자서 증강 받기·빼기, 허수아비, 단계 넘기기
/게임 증강 봇전 5 보통    # 증강 봇전: 봇 5명과 증강 야생전 (쉬움·보통·어려움·지옥, 섞기: 쉬움 3 어려움 2)
/게임 증강 봇전 관전 8 지옥  # 봇 관전전: 봇끼리만 싸우고 모두 관전 (/게임 증강 관전 으로 따라가기, /게임 증강 배속)
/게임 증강 봇전 팀 3 4 보통  # 봇전 팀전: 3명씩 4팀, 사람은 팀마다 나뉘고 빈자리는 봇 (관전 팀 3 4 보통 = 봇끼리 팀전)
/게임 중지                # 경기 강제 종료 + 모두 복구
/게임 순환 켜기           # 경기가 끝나면 다음 게임 자동 시작
/게임 설정                # 설정 메뉴 (팀 인원, 상자, 자기장, 준비 시간 …)
```

## 초능력전쟁

1. **카운트다운**: 카운트다운이 끝나면 모두 경기장(기본: 시작한 사람의 위치, 반경 60)에 흩어져 기본 킷을 받습니다. 기본 킷은 철 갑옷, 철검, 음식입니다.
2. **능력 공개**: 슬롯머신 연출로 각자의 능력이 공개됩니다. 공개 후 **15초 준비 시간** 동안은 무적이며, 웅크리고 능력 아이템을 우클릭하면 **리롤 1회**를 쓸 수 있습니다.
3. **전투**: 경기장 곳곳에 **상자**가 나타납니다. 2분 뒤부터 **자기장**이 줄어들고, 자기장 바깥에서는 계속 피해를 받습니다.
   자기장이 줄어들기 시작하면 최종 자기장 안쪽(중앙 쪽)으로 **보급 상자**가 떨어집니다(채팅으로 방향과 좌표를 알려 줍니다).
   전투 맵에서는 자기장이 줄어드는 동안 해가 져 자기장이 다 줄면 **밤**이 되고, 가끔 한동안 **비**가 내립니다.
4. **승리**: 마지막까지 살아남은 1명(팀전은 1팀)이 승리합니다.

### 조작

| 입력 | 동작 |
|---|---|
| 능력 아이템(핫바 9번)을 들고 **우클릭** | 액티브 스킬 (쿨타임은 아이템에 표시) |
| **F** (손 바꾸기) | 궁극기 (경험치 바의 게이지가 100%일 때) |
| 준비 시간에 **웅크리고 우클릭** | 능력 리롤 |

궁극기 게이지는 적에게 준 피해, 받은 피해, 그리고 시간 경과로 충전됩니다.

### 보급 상자

능력이 주인공인 게임이라 상자는 **소소하게** 나옵니다. 상자는 능력 아이템이 아닌 손(검, 빈 손 등)으로 우클릭해 열고(능력 아이템을
들고 우클릭하면 언제나 능력이 나갑니다), 모두가 같은 내용을 보므로 먼저 가져가는 사람이 임자입니다(넣을 수는 없습니다). 다 비운 상자는
닫으면 사라지고, 경기가 끝나면 모든 상자와 아이템이 사라집니다.

| 상자 | 언제 · 어디 | 들어 있는 것 (기본값) |
|---|---|---|
| 상자 (가까이 가면 은은하게 흰 반짝임) | 전투 시작 때 경기장 곳곳 (참가자 수와 경기장 크기에 비례) | 황금 사과, 음식, 엔더 진주, 활과 화살, 치유·신속·힘 물약(짧게) |
| 희귀 상자 (주황색 반짝임) | 상자 5개 중 1개꼴 | 황금 사과 2개, 엔더 진주, 초능력 전용 아이템, 가끔 다이아몬드 장비 1개(3개 중 1개꼴) |
| 보급 상자 (빛기둥 + 빛나는 표시) | 자기장이 줄어들기 시작할 때 1~2개, 최종 자기장 안쪽 | 황금 사과, 초능력 전용 아이템, 두 개 중 하나꼴로 다이아몬드 장비 |

- 아직 열지 않은 상자는 12블록 안에 들어온 플레이어(와 관전자)에게만 작게 하얗게 반짝여서, 가까이 있는 상자를 놓치지 않게 해
  줍니다 (`/게임 설정 상자반짝임 끄기`로 끌 수 있음). 희귀 상자는 모두에게 주황색으로 조금 더 반짝이고, 보급 상자는 빛기둥이 솟습니다.
- 상자는 플레이어가 걸어서 갈 수 있는 땅 위에만 놓입니다(지붕, 나무 위, 파쿠르가 필요한 탑 꼭대기, 막힌 동굴이나 건물 안, 물속에는
  놓지 않습니다). 문이나 좁은 통로 앞을 막는 자리에도 놓지 않습니다.
- **궁극기 결정**: 우클릭하면 궁극기 게이지 +25%. 궁극기를 쓴 직후의 재충전 대기 시간과 침묵 중에는 쓸 수 없습니다.
- **재충전 부적**: 우클릭하면 액티브 스킬 쿨타임이 바로 끝납니다. 침묵 중에는 쓸 수 없습니다.
- 능력 연습에는 상자가 나오지 않습니다(`loot.practice`로 켤 수 있음).

| 몸 · 변신 | 로쿠로쿠비 · 텐구 · 키르케 · 마법소녀 · 코셰이 · 마트료시카 |
| 게임 속 세상 | 격겜 고수 · 밟기 달인 · 몬스터 수집가 · 레벨업 헌터 · 이세계 트럭 |
| 장난 · 놀이 | 카드 배틀러 · 테니스 천재 · 갓파 · 야광귀 · 청개구리 |

각 능력의 패시브, 액티브, 궁극기 설명과 기본 수치는 [docs/abilities.md](docs/abilities.md)(코드에서 자동 생성)에서 보거나,
게임 안에서 `/게임 능력 목록`, `/게임 능력 정보 <능력>`으로 확인할 수 있습니다. 게임 규칙은
[docs/superpower.md](docs/superpower.md)에 있습니다.

## 증강 야생전

1. **준비**: 새 야생 월드(`mcpl_wild_<번호>`, 무작위 시드)를 만들고 플레이 구역(기본 반경 400블록, 월드보더)을 미리 생성합니다.
   진행률은 보스바에 나오고, 그동안 참가자는 제자리에서 무적으로 기다립니다.
2. **파밍 20분**: 빈손으로 월드 곳곳에 흩어져 서바이벌을 합니다. 이 동안은 모두(봇 포함) 무적이고 배고프지 않습니다
   (몹·낙하·용암도 괜찮음, `farming.invulnerable` · `farming.no-hunger`로 끌 수 있음). 전투가 시작되면 끝납니다.
3. **전투**: PvP가 켜지고 월드보더가 한 변 24블록까지 줄어듭니다. 다 줄면 모두 발광합니다. 목숨은 하나, 마지막 1명(팀)이 승리합니다.
4. **증강**: 3분·8분·13분·18분(모두 파밍 중)에 증강 라운드가 열려 모두가 같은 등급(뒤로 갈수록 높은 등급이 잘 나옴)의 카드 3장 중 하나를
   롤의 증강 선택처럼 카드가 나란히 뜨는 선택 창(대화창)에서 고릅니다. 리롤은 경기당 2번, 30초 안에 고르지 않으면
   무작위입니다(ESC로 닫아도 `/게임 증강`으로 다시 열기). 대화창이 안 보이는 클라이언트용으로 상자 메뉴(`augments.ui: CHEST`)도 있습니다.
   첫 번째 피, 심연의 광부, 기적의 착지(물 양동이 MLG!), 철의 장인, 보물 사냥꾼, 역전의 명수, 몬스터 사냥꾼, 마법사의 길을
   달성하면 보너스 증강을 하나 더 받습니다.

증강 10종(강철 체력, 철광 보따리, 깃털 낙법, 질풍, 피의 갈증, 삼중 사격, 이단 점프, 광전사의 계약, 불사조의 깃털, 다이아 광맥)의
설명과 수치는 [docs/augments.md](docs/augments.md)(코드에서 자동 생성), 규칙은 [docs/augment.md](docs/augment.md)에 있습니다.
경기 월드에서는 아이템이 떨어지고 블록을 마음대로 부수고 놓을 수 있지만, 엔더 상자·네더 차원문·리스폰 지점 설정은 막혀 있고,
경기가 끝나면 모두 원래 상태로 돌아온 뒤 월드는 지워집니다.

## 전투 맵: 폐허의 성채

무너진 성채를 중심으로 마을, 숲, 호수, 협곡, 묘지, 언덕이 둘러싸고 바깥을 부서진 성벽이 감싼 지름 약 210블록의 전투 맵입니다.
플러그인이 코드로 직접 짓기 때문에 맵 파일을 따로 받을 필요가 없습니다. 자세한 구성은 [docs/maps.md](docs/maps.md)에 있습니다.

```
/게임 경기장 맵                 # 맵 목록
/게임 경기장 맵 citadel         # 처음이면 전용 월드(mcpl_map_citadel)에 짓고(진행률 표시) 경기장으로 지정
/게임 경기장 맵 citadel 이동    # 맵 구경하러 가기
/게임 경기장 맵 citadel 다시짓기 # 처음 상태로 다시 짓기
/게임 경기장 초기화             # 맵 대신 다시 시작한 사람 위치에서 경기
```

- 맵 월드는 평소 정오·맑음에 멈춰 있고 몹이 없으며, 경기 밖에서는 관리자만 블록을 고칠 수 있습니다. 초능력전쟁 경기 중에는 해가
  져 밤이 되고 가끔 비가 내리며, 경기가 끝나거나 중지되면(서버가 경기 중 꺼졌으면 다음에 켤 때) 다시 정오·맑음으로 돌아옵니다.
- 경기 중에는 폭탄마, 크리퍼, 광부, 대지술사, 거인, 메카, 미노타우로스, 드래곤, 천문학자의 폭발·강타가 맵을 부수고, 경기가 끝나면
  맵이 한꺼번에 처음 상태로 돌아옵니다(땅은 최대 2칸까지만 파임).
- 플러그인을 업데이트해 맵이 바뀌면 `/게임 경기장 맵 citadel`을 다시 입력할 때 새 버전으로 자동으로 다시 짓습니다.

## 명령어

루트 명령어는 `/게임`입니다. 별칭은 `/mcpl`, `/mg`이며, 모든 하위 명령어에 영어 이름도 있습니다.

| 명령어 | 권한 | 설명 |
|---|---|---|
| `/게임 시작 [모드]` (`start`) | 관리자 | 경기 시작. 모드를 생략하면 순환 목록의 다음 모드 |
| `/게임 중지` (`stop`) | 관리자 | 경기 강제 종료 및 복구 |
| `/게임 목록` (`list`) | 모두 | 미니게임 목록 |
| `/게임 참가` / `/게임 관전` (`join` / `spectate`) | 모두 | 다음 경기 참가 / 관전 선택 |
| `/게임 순환 켜기·끄기·목록` (`rotation`) | 관리자 | 순환 모드 |
| `/게임 경기장 설정 [반경]` / `초기화` (`arena`) | 관리자 | 현재 위치를 경기장 중심으로 저장 / 해제 |
| `/게임 경기장 맵 [맵] [다시짓기·이동]` (`arena map [map] [rebuild/tp]`) | 관리자 | 내장 전투 맵 목록 / 맵을 지어(처음 한 번) 경기장으로 사용 / 다시 짓기 / 맵으로 이동 |
| `/게임 설정` (`settings`) | 관리자 | 설정 메뉴 열기 (콘솔에서는 현재 값 목록). 아래 [게임 안에서 설정 바꾸기](#게임-안에서-설정-바꾸기) 참고 |
| `/게임 설정 목록` (`settings list`) | 관리자 | 모든 설정의 현재 값. 줄을 클릭하면 그 설정의 명령어가 입력됩니다 |
| `/게임 설정 <항목> [값]` (`settings <name> [value]`) | 관리자 | 설정 하나 보기 / 바꾸기. 예) `/게임 설정 팀 2`, `/게임 설정 상자 끄기`, `/게임 설정 자기장 시작 90` |
| `/게임 리로드` (`reload`) | 관리자 | 설정 다시 불러오기 |
| `/게임 능력 목록` · `정보 <능력>` (`ability list/info`) | 모두 | 능력 설명 |
| `/게임 능력 리롤` (`ability reroll`) | 모두 | 준비 시간 중 리롤 |
| `/게임 능력 팀` (`ability team`) | 모두 | 팀전에서 팀원들의 능력 보기 (마우스를 올리면 설명) |
| `/게임 능력 지정 <플레이어> <능력>` (`ability assign`) | 관리자 | 다음 경기 능력 지정 (방송 연출용) |
| `/게임 능력 선택방식 <RANDOM/CHOICE>` (`ability mode`) | 관리자 | 랜덤 배정 / 후보 3개 중 선택 |
| `/게임 증강` · `목록` · `정보 <증강>` · `보너스` · `리롤` (`augment …`) | 모두 | 증강 야생전: 닫은 카드 창 다시 열기·내 증강, 증강 목록·설명, 보너스 조건, 카드 리롤 |
| `/게임 증강 연습` (`augment practice`) | 관리자(시작) · 모두(참가) | 증강 연습: 혼자서도 새 야생 월드에서 증강 시험 |
| `/게임 증강 받기 <증강>` · `빼기 <증강\|전부>` · `카드 [등급]` · `다음단계` · `허수아비 [개수]` · `대전 [켜기\|끄기]` (`give` · `take` · `cards` · `next` · `dummies` · `pvp`) | 연습 참가자 | 증강 연습 도구 |
| `/게임 증강 봇전 [봇 수] [쉬움\|보통\|어려움\|지옥]` (`augment bots`) | 관리자 | 증강 봇전: 봇이 빈자리를 채우는 증강 야생전 |
| `/게임 증강 봇전 [관전] 팀 [팀당 인원] [팀 수] [난이도]` (`augment bots [spectate] team`) | 관리자 | 봇전 팀전: 사람과 봇이 섞인 팀, 봇의 팀플레이(뭉치기·집중 공격·엄호·팀 기지) |
| `/게임 능력 연습 [능력]` · `변경 <능력>` · `충전` · `쿨타임 <켜기/끄기>` · `허수아비 [개수]` (`ability practice/switch/charge/cooldown/dummies`) | 시작·쿨타임은 관리자, 나머지는 모두 | 혼자서 훈련용 허수아비로 능력 연습 (피해량 숫자 표시, 죽어도 부활, `/게임 중지`로 종료). `/게임 시작 연습`은 모두 참가 |

권한은 두 가지입니다.
- `mcpl.admin`: 관리자 명령어. 기본값은 OP입니다.
- `mcpl.play`: 참가와 정보 확인. 기본값은 모두입니다.

## 설정

- **`config.yml`**: 아래 항목에 모두 한국어 주석이 달려 있습니다.
  - 허브 설정: 순환 목록과 대기 시간, 경기장, 카운트다운, 팀 인원, 월드 보호 항목, 능력의 지형 파괴
    (`protection.ability-block-damage`: `OFF` / `MAP_WORLDS`(기본, 전투 맵에서만) / `ALL_WORLDS`, 경기당 상한)
  - 초능력전쟁 설정(`games.superpower`): 능력 배정 방식, 리롤 횟수, 준비 시간, 제한 시간, 기본 킷, 궁극기 게이지 충전량, 자기장 타이밍, 파티클 양 배율, 팀원 능력 공개(`show-team-abilities`)
  - 하늘(`games.superpower.sky`, 전투 맵에서만): 낮과 밤(`day-night`), 비 올 확률(`rain-chance`, 기본 0.35), 비 시간(`rain-seconds`의 `min`·`max`, 기본 60~120초)
  - 보급 상자(`games.superpower.loot`): 켜기/끄기, 상자 수(참가자당 개수, 최소·최대), 일반·희귀 비율, 상자마다 아이템 수,
    아이템 목록(`pool`), 보급 상자 수와 낙하 시간, 궁극기 결정 충전량. 아이템 목록은 `"아이템 [개수 또는 최소-최대] [weight=가중치]"`
    형식이며 물약(`"POTION swiftness seconds=30"`, `"SPLASH_POTION healing level=2"`), 묶음(`"BOW + ARROW 8-12"`),
    초능력 전용 아이템(`ULTIMATE_CRYSTAL`, `RECHARGE_CHARM`)을 쓸 수 있습니다. 잘못된 줄은 콘솔 경고와 함께 건너뜁니다.
    가까운 상자 반짝임(`nearby-hint`, `nearby-hint-radius`)도 여기서 켜고 끕니다.
  - 증강 야생전 설정(`games.augment`): 월드(반경, 구조물, 난이도, 미리 생성), 파밍 시간, 월드보더(축소 대기·시간, 최종 크기,
    보더 피해, 최종 발광), 증강(선택 시간, 리롤, 라운드 시각과 등급 가중치 `augments.rounds`), 보너스 증강 켜기/끄기,
    봇 채팅(`bots.chat`: 켜기, 확률 배율, 상황별 확률)
- **`augments.yml`**: 증강마다 `enabled`와 수치, 보너스 조건마다 `enabled`, 받는 등급(`tier`), 수치.
- **`abilities.yml`**: 능력마다 `enabled`(사용 여부)와 쿨타임, 피해량, 범위 같은 모든 수치를 조정할 수 있습니다.
- 수정한 뒤 `/게임 리로드`를 입력하면 다음 경기부터 적용됩니다. 자주 바꾸는 설정은 아래처럼 게임 안에서 바꿀 수 있습니다.

### 게임 안에서 설정 바꾸기

자주 바꾸는 설정은 파일을 열지 않고 게임 안에서 바꿀 수 있습니다(관리자 권한). 바꾼 값은 `config.yml`에 바로 저장되고(주석은
그대로 남습니다), 진행 중인 경기에는 적용되지 않고 **다음 경기부터** 적용됩니다. 경기 시작 카운트다운 중에 바꾼 값은 곧 시작할
경기에 적용됩니다(카운트다운 시간과 능력 지형 파괴만 다음 경기부터). 범위를 벗어난 값은 범위 끝으로 맞춥니다.
`config.yml`에 문법 오류가 있는 동안에는 파일을 덮어쓰지 않도록 모든 변경을 거부합니다. 서버가 켜진 채로 `config.yml`을 직접
고쳤다면 `/게임 리로드`로 불러오기 전까지 게임 안의 변경을 거부합니다(고친 내용을 덮어쓰지 않도록). 저장에 실패하면(디스크가 가득
참 등) 그렇다고 알려 줍니다.

- **설정 메뉴** (`/게임 설정`): 항목마다 현재 값(최댓값·최솟값이면 그렇다고), 범위, 기본값, 설명, 같은 일을 하는 명령어,
  경기 중이면 다음 경기부터 적용된다는 안내가 보입니다.
  켜기/끄기는 클릭, 숫자는 좌클릭 +, 우클릭 -, Shift+클릭은 크게, 선택지는 좌클릭 다음 · 우클릭 이전, **Q**(버리기 키)는 기본값으로.
  메뉴에서 아이템을 꺼내거나 넣을 수는 없고, 경기 중에도 열 수 있습니다.
- **명령어**: `/게임 설정 <항목> <값>`. 항목 이름만 입력하면 현재 값과 사용법을 보여 줍니다. 탭 자동 완성을 지원합니다.

| 항목 | 명령어 (영어) | 값 | `config.yml` |
|---|---|---|---|
| 팀 인원 | `팀 <인원>` (`team`) | 0(개인전) ~ 32 | `match.team-size` |
| 카운트다운 | `카운트다운 <초>` (`countdown`) | 0 ~ 60초 | `match.countdown-seconds` |
| 능력 지형 파괴 | `지형파괴 끄기·맵에서만·모든월드` (`terrain off·maps·all`) | | `protection.ability-block-damage` |
| 능력 배정 방식 | `선택방식 무작위·선택` (`mode random·choice`) | | `games.superpower.selection.mode` |
| 리롤 횟수 | `리롤 <횟수>` (`rerolls`) | 0 ~ 10 | `…selection.rerolls` |
| 준비 시간 | `준비시간 <초>` (`prep`) | 0 ~ 300초 | `…prep-seconds` |

## 개발

- 구조와 규칙은 [CLAUDE.md](CLAUDE.md)를, 게임 규칙은 [docs/](docs/)를 참고하세요.
- 새 미니게임을 추가할 때는 `core.game.MiniGame`을 구현해 `MCPLPlugin#registerGames`에서 등록합니다.
- 새 능력을 추가할 때는 `Ability`를 상속해 `BuiltinAbilities`에 등록합니다.
- 새 증강을 추가할 때는 `Augment`를 구현해 `BuiltinAugments`에 등록하고 `./gradlew updateAugmentDocs`로 문서를 다시 만듭니다.
