# 초능력전쟁 (Superpower War) — 설계 문서

옛 마인크래프트 고전 콘텐츠 "초능력전쟁/능력자 전쟁"을 최신 버전(Paper 26.3)에 맞게 리마스터한 모드입니다.
MCPL 플러그인 하나에 여러 미니게임이 들어가며, 초능력전쟁은 그 첫 번째 모드입니다.

## 1. 핵심 원칙

- **설치 즉시 플레이**: jar를 넣고 `/게임 시작 초능력전쟁` 한 줄이면 됩니다. 전용 맵 없이 현재 월드에서 진행하고,
  경기가 끝나면 모든 참가자의 인벤토리·위치·체력·경험치·게임모드·효과가 **경기 전 상태로 복구**됩니다.
- **월드 보호**: 경기 중 블록 파괴/설치, 폭발 블록 파괴, 불 번짐, 문/버튼 상호작용 등 월드 변경을 막습니다.
  능력이 만드는 블록(얼음 감옥 등)은 모두 임시 블록이며 자동으로 원상 복구됩니다.
- **보는 재미**: 능력 공개 슬롯머신 연출, 궁극기 전체 공지, 킬로그, 관전 HUD, 경기 결산(순위·킬·피해량·MVP).
- **2명~20명+**: 개인전 기본, 팀전 지원(`/게임 설정 팀 <팀당 인원>`).
- **설정 가능**: `config.yml`(진행), `abilities.yml`(능력별 수치·사용 여부). 모든 메시지는 한국어 MiniMessage.

## 2. 진행 흐름

| 단계 | 내용 |
|---|---|
| 대기 | 관리자가 `/게임 시작 초능력전쟁` 또는 순환 모드가 자동 시작. 참가자 = 접속 중이며 관전을 선택하지 않은 플레이어(최소 2명). |
| 카운트다운 | 5초 타이틀 카운트다운. 참가자 상태 저장(스냅숏, 디스크에도 기록) 후 초기화. |
| 배치 | 경기장(기본: 시작한 관리자의 위치, 반경 60) 안 안전한 지점으로 서로 떨어뜨려 분산 텔레포트, 기본 킷 지급. |
| 능력 공개 | 슬롯머신 연출(타이틀에 능력 이름이 빠르게 돌다 느려지며 확정, 틱 효과음, 약 3초). 선택 방식: `RANDOM`(기본, 중복 최소화, 준비 시간 중 리롤 1회) / `CHOICE`(후보 3개 중 메뉴에서 선택, 시간 초과 시 랜덤). |
| 준비 시간 | 15초 무적, 능력 사용 불가. 능력 아이템 설명과 채팅 요약으로 능력 확인. |
| 전투 | 능력 사용 가능. 자기장(가상 월드보더)이 일정 시간 후 서서히 줄어들고 바깥은 지속 피해. |
| 탈락 | 사망 시 즉시 관전 모드(경기장 안). 킬로그: `☠ 처치자(능력) → 피해자(능력)`. 사망해도 아이템은 떨어지지 않음. |
| 종료 | 최후의 1인(팀전은 1팀) 승리. 제한 시간 초과 시 킬 수 → 남은 체력 순으로 승자 결정. 승리 타이틀·폭죽·채팅 결산. |
| 복구 | 약 10초 후 모든 참가자를 경기 전 상태/위치로 복구. 순환 모드면 다음 게임 대기(보스바 카운트다운). |

서버가 경기 중 꺼지거나 플레이어가 나가도, 다음 접속 때 저장된 스냅숏으로 복구됩니다.

## 3. 조작

| 입력 | 동작 |
|---|---|
| 능력 아이템(핫바 9번 칸) 들고 **우클릭** | 액티브 스킬 (쿨타임은 아이템 쿨타임 오버레이로 표시) |
| **F** (손 바꾸기) | 궁극기 (게이지 100%일 때) |
| 준비 시간 중 능력 아이템 **웅크리고 우클릭** | 리롤 (RANDOM 모드, 1회) |

- 능력 아이템은 옛 "능력자" 플러그인을 기리는 **철괴** 기반이며, 아이템 모델은 능력 아이콘으로 표시됩니다. 버리거나 옮길 수 없습니다.
- 궁극기 게이지는 **경험치 바**에 표시됩니다(레벨 숫자 = 게이지 %). 가한 피해, 받은 피해, 시간 경과로 충전됩니다.
- 사이드바: 생존자 수, 내 킬, 자기장 상태, 내 능력/쿨타임. 보스바: 다음 자기장 단계까지 남은 시간.

## 4. 능력 목록 (76종)

능력별 패시브·액티브·궁극기 설명과 기본 수치는 **[abilities.md](abilities.md)** 에 있습니다. 이 목록은 능력 코드의
정의(`AbilityInfo`)에서 자동 생성되므로 항상 실제 동작·수치와 같습니다(`./gradlew updateAbilityDocs`).

- 수치는 기본값이며 `abilities.yml`에서 능력별로 조정하거나 끌 수 있습니다. 피해 단위는 체력 포인트(20 = 하트 10칸)이고,
  능력 피해는 기본적으로 마법 피해(방어구 무시)입니다. 기본 킷은 철 갑옷 + 철검 기준입니다.
- 20개 분류: 원소, 기동 · 암살, 근접 · 탱커, 제어, 원거리 · 소환 · 지원, 특수, 자연, 빛 · 소리 · 정신, 무기, 기술,
  변신 · 생물, 주술 · 트릭, 격투 · 공간 · 건축, 직업, 무대 · 스포츠, 어둠 · 영혼, 마인크래프트 몹, 기계 · 우주,
  버섯 · 수정 · 예술, 사냥 · 모험.
- 밸런스 기준: 능력 피해는 방어구를 무시하므로 액티브는 대체로 4~6 피해 / 6~12초 쿨타임, 하드 CC는 2~3초 이하,
  풀피 원콤은 없고, 궁극기는 크지만 피하거나 끊을 수 있게 예고 연출이 있습니다.
- 모든 능력은 적(`isEnemy`)에게만 피해를 주며 팀전·관전자·킬 크레딧이 자동으로 처리됩니다. 능력이 만든 블록과 엔티티는
  경기가 끝나면 모두 사라집니다.

## 5. 명령어 (요약)

루트 명령어 `/게임` (별칭 `/mcpl`, `/mg`).

| 명령어 | 권한 | 설명 |
|---|---|---|
| `/게임 시작 [모드]` | 관리자 | 경기 시작 (모드 생략 시 순환 목록의 다음 모드) |
| `/게임 중지` | 관리자 | 진행 중인 경기 강제 종료 및 복구 |
| `/게임 목록` | 모두 | 사용 가능한 미니게임 목록 |
| `/게임 참가` / `/게임 관전` | 모두 | 다음 경기 참가 / 관전 선택 |
| `/게임 순환 <켜기/끄기>` | 관리자 | 경기가 끝나면 다음 모드를 자동으로 시작 |
| `/게임 경기장 설정 [반경]` | 관리자 | 현재 위치를 경기장 중심으로 저장 |
| `/게임 설정 팀 <팀당 인원>` | 관리자 | 0 = 개인전 |
| `/게임 리로드` | 관리자 | 설정 다시 불러오기 |
| `/게임 능력 목록` / `/게임 능력 정보 <능력>` | 모두 | 능력 설명 |
| `/게임 능력 지정 <플레이어> <능력>` | 관리자 | 다음/현재 경기의 능력 지정(방송 연출용) |
| `/게임 능력 선택방식 <RANDOM/CHOICE>` | 관리자 | 능력 배정 방식 |
| `/게임 능력 연습 [능력]` | 관리자(시작) / 모두(참가) | 능력 연습 시작·참가, 연습 중이면 능력 변경 |
| `/게임 능력 변경 <능력>` · `충전` · `허수아비 [개수]` | 모두 | 연습 중: 능력 바꾸기, 궁극기 100%, 허수아비 다시 세우기 |
| `/게임 능력 쿨타임 <켜기/끄기>` | 관리자 | 연습 중: 액티브 쿨타임 켜기/끄기 |

## 6. 능력 연습 (`/게임 능력 연습`)

진짜 경기는 최소 2명이 필요하므로, 혼자서도 능력의 손맛과 연출을 확인할 수 있는 연습 모드(`practice`, 미니게임
이름 「능력 연습」)를 따로 둡니다. 진짜 경기와 **같은 경기 코드**로 돌아가므로 능력의 동작과 파티클·디스플레이 연출이
실제 경기와 똑같습니다. 순환 목록에는 들어가지 않습니다.

- **시작**: `/게임 능력 연습 [능력]` (관리자) — 명령어를 쓴 사람만 참가하고 나머지는 관전합니다. 능력을 생략하면 무작위.
  `/게임 시작 연습`은 접속 중인 모두가 참가합니다. 허브의 카운트다운, 스냅샷 복구, 월드 보호, 임시 블록은 그대로입니다.
- **진행**: 능력 공개·준비 시간 없이 바로 전투 상태로 시작합니다. 자기장은 줄어들지 않고 제한 시간과 승패도 없습니다.
  `/게임 중지` 또는 참가자가 모두 나가면 끝나고, 모두 원래 상태로 복구됩니다.
- **훈련용 허수아비**: 참가자마다 앞쪽 5·8·11블록에 마네킹 3개가 섭니다(먼 것도 조준할 수 있게 좌우로 엇갈림).
  모든 참가자의 **적**으로 취급되어 대상 지정·범위 공격·소환수·적중 효과가 그대로 통하고, 준 피해로 궁극기 게이지가 찹니다.
  맞을 때마다 빨간 피해량 숫자가 떠오르고, 이름 아래에 체력이 보입니다. AI가 없어 가만히 서 있지만 넉백·속박·빙결 등은
  그대로 받습니다. 3초 동안 맞지 않으면 체력이 다시 차고 제자리로 돌아가며, 죽거나 사라지거나 멀리 날아가면 다시 섭니다.
- **죽음**: 탈락하지 않고 연습 위치에서 바로 부활하며, 킷과 능력을 새로 받습니다.
- **연습 명령어**: `변경 <능력>`(이전 능력을 정리하고 새 능력 부여, 체력 회복), `충전`(궁극기 100%), `쿨타임 <켜기/끄기>`
  (기본은 켜짐, 끄면 액티브를 바로 다시 쓸 수 있음), `허수아비 [개수]`(지금 바라보는 방향에 다시 세우기, 1~10개).
  진행 중인 연습에서 `/게임 능력 연습 [능력]`을 쓰면 관전자는 참가하고 참가자는 능력이 바뀝니다. 진짜 경기 중에는 모든
  연습 명령어가 거부됩니다.
- **설정** (`config.yml` → `games.practice`): 쿨타임 기본값, 허수아비 수·거리·간격·체력·회복 시간, 피해량 숫자 표시.
  킷, 게이지 충전량, 파티클 배율 등 나머지는 `games.superpower` 설정을 그대로 씁니다.
