# 초능력 공성전 v2 — 설계 (장난감 왕국, 2라인)

v1(공수 교대, 네온 시티)을 대체합니다. 사용자 피드백: 이해가 어렵고 정신없음 → **단순하고 한눈에 읽히게**.
모든 수치는 `games.siege.*` 설정. 이 문서가 v2 규칙의 기준이며, 구현이 끝나면 docs/siege.md 에 합칩니다.

## 0. 원칙
- 화면 정보 최소화: 보스바는 남은 시간 1줄, 사이드바 5~6줄(점수, 시간, 내 레벨·골드, 다음 큰 오브젝트).
- 늘 한 줄 안내("▶ 지금 할 일") + 시작 20초 규칙 안내(타이틀 3장 + 채팅 요약).
- 체력은 머리 위(디스플레이 엔티티 바), 들어간 데미지는 떠오르는 숫자. 보스바로 체력 표시 금지.
- 타격·파괴·경고 소리는 재질에 맞게, 반복은 간격을 둠.

## 1. 규칙
- 두 팀(BLUE −x 진영, RED +x 진영), 인원 자유(혼자 테스트 가능). 대칭 맵.
- **2라인**: TOP(−z)과 BOTTOM(+z), 롤의 탑·바텀처럼 바깥으로 휘어짐. 가운데는 강/정글, 중앙에 **장난감 드래곤** 구덩이.
- 건물: 팀마다 **라인당 타워 2개**(바깥 → 안쪽) + **코어 1개**. 바깥 타워가 서 있으면 그 라인 안쪽 타워는 보호막;
  두 라인의 안쪽 타워 중 하나라도 서 있으면 코어 보호막.
- **판**: 제한 시간(기본 20분) 점수전. 코어 파괴 시 **시간과 무관하게 즉시 승리**. 시간 종료 시 점수 높은 팀(동점 → 부순 타워
  → 킬 → 2분 연장). **3판 2선승**(판 사이 1분).
- 점수(기본): 킬 +2, 어시스트 +1, 미니언 처치 +0(골드만), 정글 소형 +1, 버프몹 +3, 점령지 +2, 드래곤 +10, 타워 +8.
- 부활: 6초(+1초/이번 판 사망 3회, 최대 14초), 본진 분수에서 부활, 3초 보호.
- 능력: 처음부터 모두 사용(레벨 잠금 없음). 레벨은 강화만(§5).

## 2. 미니언
- 30초마다 각 팀 본진에서 **두 라인**으로 출발: 근접 3 + 원거리 2(인원 많으면 +1), 3웨이브마다 대포(탱커) 1.
- 라인 경로(`LaneSites#lanePath`)를 따라 걷고, 마주친 적 미니언/플레이어/타워를 공격. 타워는 미니언을 우선 공격.
- 귀여운 3D 모델(태엽 병정 근접, 장난감 궁수 원거리, 장난감 대포), 리소스팩 없는 사람에겐 바닐라 대체 모습.

## 3. 골드와 상점
- 골드: 초당 +1, 미니언 막타 +15(대포 +40), 킬 +150(어시 +50), 정글 소형 +40, 버프몹 +90, 점령지 +60, 드래곤 팀 전원 +200,
  타워 팀 전원 +120.
- 상점: **자기 본진 상점 앞(반경 8칸)**에서만. 메뉴(상자)로 구매, 아이템 칸 **6개 제한**, 판이 끝나면 초기화(반 개념 없음).
- 품목(초안, 수치는 설정):

| 분류 | 품목 | 효과 | 가격 |
|---|---|---|---|
| 기본 | 체력 사탕 | 10초에 걸쳐 체력 8 회복, 3개 묶음, 소모품 | 50 |
| 기본 | 장난감 갑옷 1·2·3단계 | 근접·화살 방어 + **스킬 피해 −6/−12/−18%** | 400/800/1300 |
| 공격 | 나무검 → 강철검 | 평타 피해 +1.5 / +3 | 350/850 |
| 공격 | 마법 구슬 | 스킬 피해 +10% | 900 |
| 유틸 | 태엽 신발 | 이동속도 +8% (중첩 불가) | 300 |
| 유틸 | 모래시계 장신구 | 쿨타임 −10% | 800 |
| 유틸 | 귀환 깃발 | 8초 정신 집중 후 본진 귀환(피격 시 취소), 무한 사용 | 기본 지급 |

| 생존 | 부활 시계 | 부활 시간 −2초 | 600 |

## 4. 정글 오브젝트 (진영마다 6종 + 중앙 1)
| 종류 | 이름 | 형태 | 보상 | 재생성 |
|---|---|---|---|---|
| JELLY | 젤리 무리 | 몬스터 3(작음) | 골드·경험치 소 | 60초 |
| MICE | 태엽 쥐 떼 | 몬스터 4(아주 작음, 빠름) | 골드·경험치 소 | 60초 |
| TEDDY | 곰인형 대장 | 몬스터 1(1.5배) | 공격 버프 90초 | 150초 |
| RABBIT | 시계 토끼 | 몬스터 1(1.5배, 도망 다님) | 쿨타임 감소 버프 90초 | 150초 |
| FOUNTAIN | 사탕 샘물 | 점령 지점(8초) | 팀 즉시 회복 + 10초 재생 | 90초 |
| TELESCOPE | 망원경 탑 | 점령 지점(8초) | 60초 동안 맵 절반의 적 위치 공개(발광) | 120초 |

- 몬스터는 맞기 전엔 가만히, 끌고 가면 돌아가며 회복(리쉬), 위에 이름·체력바, 죽으면 재생성 타이머.
- 각 오브젝트는 모양·색·크기가 확 다르게(귀엽게). 사이드바에는 드래곤·버프몹 타이머만.

## 5. 레벨과 능력 밸런스 (공성전만)
- 레벨 1→9(경험치: 미니언, 정글, 킬, 타워, 드래곤, 시간). **레벨이 능력을 잠그지 않음.**
- 공성전에서 능력 피해 **기본 −35%**(설정) + 능력별 보정표(한 방 최대치·초당 피해·통제기 비교로 튀는 능력 개별 조정).
- 레벨당 능력 피해 +7.5% (9레벨 +60%), 체력 +1칸/2레벨.
- 3·6·9레벨 **추가 효과**(능력별 1줄, 억까 금지: 통제기 지속 증가는 레벨당 상한 +0.5초, 즉사·영구 효과 금지).

## 6. 맵: 장난감 왕국
- 약 200×120, 대칭. 파스텔 장난감 성(BLUE 파랑 성, RED 빨강 성), 휘어진 두 라인 길, 중앙에 강과 드래곤 구덩이.
- 구역마다 주재료 2~3개, 장식 절제, 길과 벽 대비 확실. 라인 바닥 색: TOP = 노랑 벽돌길, BOTTOM = 하늘색 벽돌길.
- 계약: `core/map/lanes/LaneSites` (스폰, 상점, 타워, 코어, 라인 경로, 오브젝트, 드래곤, 지역).

## 7. 리소스팩 (새 맵 컨셉, 귀엽게)
- 타워(장난감 성 망루), 코어(왕관 쓴 오르골 성), 미니언 3종, 정글 6종 + 드래곤, 상점 주인(태엽 상인), 보호막(비눗방울 돔).
- 셰이더: 장난감 왕국 색감(부드러운 파스텔, 은은한 안개)과 비눗방울 보호막 무지개빛 — 이 맵에서만.
- 직업 무기 50종은 그대로.

## 8. (다음) 직업별 기본 공격 스킬 — 메이플스토리식
- 평타(좌클릭)를 그냥 칼질이 아니라 **직업마다 고유한 기본 공격 스킬**로 바꿈(메이플의 매직 클로·더블 스탭·애로우 블로우처럼).
  능력 50종마다: 공격 형태(근접 휘두르기/찌르기/연타, 짧은 투사체, 근거리 범위), 사거리·타수·속도, 고유 이펙트와 소리,
  능력 컨셉에 맞는 작은 부가효과(예: 빙결술사 = 서리 구슬 투사체 + 약한 감속, 요리사 = 칼질 2연타).
- 평타 피해는 레벨·상점 아이템(검)과 함께 성장. 스킬보다 약하지만 꾸준히 쓰는 주력.

## 9. (다음) 공성전 봇전
- 혼자서도 공성전을 즐길 수 있게 봇 팀원/상대. 기존 능력 50종 연동은 어렵기 때문에 **봇 전용 직업 몇 개**(예: 전사·궁수·
  마법사·탱커·치유사)를 단순한 스킬셋으로 따로 만든다. 라인 밀기, 미니언 막타, 타워 공격, 정글·드래곤, 귀환·상점 이용.
