# 전투 맵

MCPL은 전투 맵을 코드로 직접 짓습니다. 맵마다 전용 빈 월드(`mcpl_map_<맵>`)가 하나씩 생기고, 서버의 다른 월드는 건드리지
않습니다. 관리자가 `/게임 경기장 맵 <맵>`을 처음 입력하면 맵을 짓고(진행률 표시), 그 뒤로는 서버를 켤 때마다 지어 둔 월드를
그대로 불러옵니다.

| 명령어 | 설명 |
|---|---|
| `/게임 경기장 맵` | 맵 목록과 상태(준비됨 / 아직 짓지 않음 / 새 버전 있음) |
| `/게임 경기장 맵 <맵>` | 맵을 지어(처음이거나 새 버전일 때만) 경기장으로 지정. 경기는 맵 중심에서 맵 반경으로 진행 |
| `/게임 경기장 맵 <맵> 다시짓기` | 맵 월드를 지우고 처음 상태로 다시 짓기 |
| `/게임 경기장 맵 <맵> 이동` | 맵 중심으로 이동 (구경, 촬영용) |
| `/게임 경기장 초기화` | 맵 대신 다시 시작한 사람의 위치에서 경기 |

맵 월드의 규칙:
- 항상 낮(정오)이고 맑으며, 몹이 생기지 않습니다.
- 물·용암이 흐르지 않고, 나뭇잎이 시들지 않고, 풀·불이 번지지 않습니다.
- 경기 밖에서는 관리자만 블록을 부수거나 놓을 수 있습니다. 경기 중에는 다른 경기장과 똑같이 월드 보호가 적용되고,
  능력이 만든 블록은 경기가 끝나면 사라집니다.
- 플러그인을 업데이트해 맵이 바뀌면 목록에 "새 버전 있음"이 표시되고, `/게임 경기장 맵 <맵>`을 입력할 때 자동으로 다시 짓습니다.

## 폐허의 성채 (`citadel`)

무너진 성채를 중심으로 여섯 구역이 둘러싸고, 바깥을 부서진 성벽이 감싼 지름 약 210블록(경기 반경 105)의 전장입니다.
2~20명이 초능력으로 싸우도록 만들었습니다.
- 8~12블록마다 엄폐물이 있습니다.
- 높은 곳은 계단이나 경사로로 여러 방향에서 오를 수 있습니다.
- 빠져나올 수 없는 구덩이나 막다른 함정이 없습니다.
- 자기장이 줄어들면 마지막 싸움은 성채 안뜰에서 벌어집니다.

```
                 북 (−z)
         협곡     묘지     언덕
  서 (−x)         성채          동 (+x)
         호수      숲      마을
                 남 (+z)
```

| 구역 | 방향 | 모습 |
|---|---|---|
| 성채 | 중심 (반경 30) | 무너진 외벽과 성문, 안뜰, 3층짜리 중앙 탑과 작은 탑들. 자기장이 줄어든 뒤의 결전 장소 |
| 마을 | 동~남동 | 무너진 중세 마을. 집, 골목, 시장, 올라갈 수 있는 종탑 |
| 숲 | 남 | 오래된 숲. 여러 종류의 나무와 거목, 사냥꾼 오두막, 안으로 올라갈 수 있는 거대한 빈 나무 |
| 호수 | 남서~서 | 섬이 있는 호수. 다리와 선착장, 섬의 폐허, 물레방아 |
| 협곡 | 서~북서 | 구불구불한 협곡. 줄다리·돌다리·쓰러진 통나무로 건너고, 계단과 경사로로 오르내림. 바위 능선을 뚫은 동굴 |
| 묘지 | 북 | 묘비와 지하 묘실, 높은 단 위의 무너진 신전 |
| 언덕 | 북동~동 | 완만한 언덕, 언덕 위 망루, 군 야영지, 풍차 폐허 |
| 외곽 성벽 | 가장자리 (반경 97~124) | 망루와 성문이 있는 부서진 성벽. 성벽 위를 걸을 수 있고, 무너진 틈으로 바깥 언덕과 이어짐 |

- 성채를 둘러싼 돌길(반경 31~36)과 여섯 방향으로 뻗은 흙길이 모든 구역을 잇습니다.
- 경기장 밖으로 밀려나도 바깥 언덕에 떨어지므로 성문이나 무너진 틈으로 걸어 들어올 수 있습니다.

## 맵 만들기 (개발)

- 맵은 `ArenaMap`을 구현해 `MCPLPlugin`에서 `hub.maps().register(...)`로 등록합니다. 블록은 `MapCanvas`에 `BlockSpec`(방향,
  반 블록, 계단 모양 같은 속성을 담은 블록)으로 그리고, `MapService`가 전용 월드에 틱마다 나눠서 놓습니다.
- 폐허의 성채는 `CitadelLayout`(반경, 구역 각도, 길)이 설계도이고, 구역마다 `MapZone` 클래스가 하나씩 있습니다. 각 구역은 자기
  구역 안에만 블록을 놓을 수 있습니다.
- `./gradlew renderMaps [-Pzone=<구역>]`은 위에서 본 그림과 등각 투영 그림을 `build/map-previews/`에 PNG로 만듭니다.
- `CitadelMapTest`는 맵 전체를 검사합니다.
  - 설 수 있는 모든 곳에 걸어서 갈 수 있고, 빠져나올 수 없는 구덩이가 없는지
  - 떠 있는 모래, 넘치는 물, 용암·불이 없는지
- 맵 블록을 바꾸면 `ArenaMap#version`을 올려야 서버가 새로 짓습니다.
