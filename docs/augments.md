# 증강 야생전 증강 목록 (27종)

수치는 기본값이며 `augments.yml`에서 조정할 수 있습니다. 체력 단위는 체력 포인트(2 = 하트 1칸)입니다. 게임 규칙은 [augment.md](augment.md)를 보세요.

| 등급 | 증강 |
|---|---|
| 실버 | 강철 체력, 철광 보따리, 깃털 낙법, 질풍, 날카로운 칼날, 단단한 피부, 화살통, 방패술, 불꽃 칼날, 독침 |
| 골드 | 피의 갈증, 삼중 사격, 이단 점프, 광전사의 계약, 처형자, 연타, 저격수, 가시 갑옷, 강타, 얼음 화살, 폭발 화살 |
| 프리즘 | 불사조의 깃털, 다이아 광맥, 거인화, 그림자 일격, 전쟁의 신, 강철 요새 |

## 실버

| 증강 | 종류 | 효과 |
|---|---|---|
| **강철 체력** `iron_body` | 능력치 | 최대 체력이 4 늘어나고(체력 2 = 하트 1칸) 늘어난 만큼 바로 회복합니다. |
| **철광 보따리** `iron_bundle` | 자원 | 철 주괴 12개와 빵 6개를 바로 받습니다. |
| **깃털 낙법** `feather_fall` | 기동 | 떨어질 때 받는 피해가 100% 줄어듭니다. |
| **질풍** `gale` | 능력치 | 이동 속도가 15% 빨라집니다. |
| **날카로운 칼날** `sharp_edge` | 전투 | 적에게 주는 근접 공격 피해가 1.5 늘어납니다. |
| **단단한 피부** `thick_skin` | 능력치 | 근접 공격으로 받는 피해가 10% 줄어듭니다. |
| **화살통** `quiver` | 자원 | 화살 64개를 바로 받고, 활을 쏠 때 30% 확률로 화살을 쓰지 않습니다. |
| **방패술** `shield_master` | 전투 | 방패를 받습니다. 방패로 적의 근접 공격을 막으면 공격한 적이 피해 2를 받습니다. |
| **불꽃 칼날** `fire_blade` | 전투 | 근접 공격이 적을 2초 동안 불태웁니다 (재사용 4초). |
| **독침** `venom` | 전투 | 근접 공격이 적에게 2초 동안 독 2을 겁니다 (재사용 4초). |

## 골드

| 증강 | 종류 | 효과 |
|---|---|---|
| **피의 갈증** `bloodthirst` | 전투 | 적(상대 플레이어, 적대적 몹)에게 준 피해의 20%만큼 체력을 회복합니다. |
| **삼중 사격** `triple_shot` | 전투 | 활 1개와 화살 32개를 받습니다. 활이나 쇠뇌를 쏘면 좌우 10도로 화살 2발이 더 나가며, 추가 화살은 피해가 60%이고 주울 수 없습니다. |
| **이단 점프** `double_jump` | 기동 | 공중에서 점프 키를 한 번 더 누르면 위로 0.9, 앞으로 0.6만큼 도약합니다 (재사용 3초, 땅에 닿아야 다시 충전). |
| **광전사의 계약** `berserker_pact` | 양날의 검 | 최대 체력이 4만큼 줄어드는 대신, 적에게 주는 모든 피해가 25% 늘어납니다. |
| **처형자** `executioner` | 전투 | 체력이 최대 체력의 30% 이하인 적에게 주는 모든 피해가 30% 늘어납니다. |
| **연타** `combo` | 전투 | 같은 적을 3초 안에 근접 공격으로 3번 때리면 마지막 공격의 피해가 4 늘어납니다. |
| **저격수** `sniper` | 전투 | 20블록 이상 떨어진 적을 화살로 맞히면 피해가 50% 늘어납니다. |
| **가시 갑옷** `thorns` | 전투 | 적의 근접 공격으로 받은 피해의 20%를 공격한 적에게 돌려줍니다. |
| **강타** `heavy_hitter` | 전투 | 근접 공격의 밀치기가 크게 늘어납니다 (밀치기 마법부여 2레벨만큼). |
| **얼음 화살** `frost_arrow` | 전투 | 화살에 맞은 적이 2초 동안 구속 2에 걸립니다. |
| **폭발 화살** `blast_arrow` | 전투 | 활이나 쇠뇌로 3발째마다 쏜 화살(빛남)이 맞은 곳에서 작게 폭발해 반경 3블록 안의 적에게 피해 4를 줍니다 (블록은 부서지지 않음). |

## 프리즘

| 증강 | 종류 | 효과 |
|---|---|---|
| **불사조의 깃털** `phoenix_feather` | 특수 | 한 번, 죽을 만큼의 피해를 받으면 대신 체력 10로 되살아나 3초 동안 거의 무적이 되고 6초 동안 재생합니다. (공허에 떨어졌다면 땅 위로 돌아옵니다) |
| **다이아 광맥** `diamond_vein` | 자원 | 다이아몬드 5개를 바로 받고, 다이아몬드 광석을 캘 때마다(섬세한 손길 제외) 다이아몬드가 1개 더 나옵니다. |
| **거인화** `giant` | 양날의 검 | 몸이 30% 커지고 최대 체력이 8 늘어나는 대신(늘어난 만큼 바로 회복), 이동 속도가 10% 느려집니다. |
| **그림자 일격** `shadow_strike` | 전투 | 웅크리기(Shift)를 3초 동안 누르고 있으면 5초 동안 투명해지고, 그동안 다음 근접 공격의 피해가 200%가 됩니다 (공격하면 투명 해제, 재사용 10초). |
| **전쟁의 신** `war_god` | 전투 | 적 플레이어를 처치할 때마다 공격력이 1씩(최대 5번) 늘어나고 체력을 4 회복합니다. |
| **강철 요새** `fortress` | 능력치 | 입은 갑옷과 별개로 방어력 +4, 방어 강도 +4, 밀치기 저항 50%를 얻습니다. |

## 보너스 증강 조건

조건마다 한 번, 달성하면 그 등급의 증강 카드 3장 중 하나를 더 고릅니다. **선착순** 조건은 경기에서 가장 먼저 달성한 한 명만 받습니다.

| 조건 | 등급 | 선착순 | 내용 |
|---|---|---|---|
| **첫 번째 피** `first_blood` | 골드 | 예 | 이번 경기에서 처음으로 다른 플레이어를 처치합니다. |
| **심연의 광부** `abyss_miner` | 골드 |  | Y -40 아래에서 다이아몬드 광석을 캡니다. |
| **기적의 착지** `miracle_landing` | 실버 |  | 20블록 이상 떨어지고도 살아남습니다: 물에 착지하거나(물 양동이 MLG), 체력이 4 이하로 남은 채로 (체력 2 = 하트 1칸). |
| **철의 장인** `iron_artisan` | 실버 | 예 | 가장 먼저 철 이상(철·다이아몬드·네더라이트) 갑옷 네 부위를 모두 입습니다. |
| **보물 사냥꾼** `treasure_hunter` | 실버 |  | 자연적으로 생성된 보물 상자(마을, 폐광, 난파선, 사막 사원 …)를 처음 엽니다. |
| **역전의 명수** `comeback` | 골드 |  | 나보다 체력이 많던 상대(최근 30초 안의 교전 기준)를 처치하거나, 내 체력이 6 이하일 때 플레이어를 처치합니다 (체력 2 = 하트 1칸). |
| **몬스터 사냥꾼** `monster_hunter` | 실버 |  | 파밍 시간 동안 적대적 몹을 10마리 처치합니다. |
| **마법사의 길** `mage_path` | 실버 |  | 마법 부여대에서 처음으로 아이템에 마법을 부여합니다. |
