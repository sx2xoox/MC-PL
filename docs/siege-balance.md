공성전 능력 풀(`games.siege.ability-pool` 기본값)의 스킬·궁극기 밸런스입니다. 초능력전쟁은 이 표와 상관없이 그대로입니다. 피해·회복 단위는 체력 포인트(20 = 하트 10칸), 시간은 초, 거리는 블록입니다. 평타(`BasicAttacks`)는 따로 다룹니다(docs/siege-v2.md §8).

## 측정 방법 (밸런스 랩)

`SiegeBalanceLab`(`./gradlew siegeLab`)이 능력마다 1·6·9레벨에서 테스트 서버의 실제 공성전 경기(MockBukkit, 물리 있는 평지)를 돌려 `docs/siege-balance-lab.csv` 에 씁니다. 공격자는 스스로 움직이지 않고 매 틱 대상을 조준하며, 적은 제자리에 서서 매 틱 체력이 다시 차서 죽지 않습니다. 같은 팀 1명이 공격자 뒤 2블록에 섭니다. 나머지는 모두 효과 없는 더미 능력입니다. 능력별 보정은 1로 두고 재며(보고서가 곱함), 공성전 전용 수치·특성은 켜고 잽니다.

| 장면 | 내용 | 지표 |
|---|---|---|
| 사거리 (1레벨) | 3·5·8·12·18·26블록에서 액티브 한 번 | 유효 사거리 = 최고의 절반 이상 맞는 가장 먼 거리, 결투 거리 = 최고의 90% 이상인 가장 먼 거리 |
| 결투 30초 | 쿨마다 액티브(시전 전 제자리로), 0.5초마다 대상이 공격자·아군에게 시험타 2 | 초당 피해, 대상 통제, 넉백, 공격자 이동, 회복·보호막·막은 피해·무적, 아군 지원 |
| 궁극기 12초 | 0초 궁극기 + 쿨마다 액티브, 결투 거리와 4블록 중 나은 쪽 | 궁극기 몫 = 이 장면 − 결투 첫 12초 |
| 밀집 10초 | 적 5명이 1.2블록 안에 모임, 궁극기 + 액티브 | 대상별 피해 → 광역(둘째 이후 대상 합) |
| 타워 20초 | 적 바깥 타워 5블록 앞(타워는 쏘지 않음), 궁극기 + 액티브 | 건물 피해 |
| 근접 12초 | 2.5블록에서 평타만(공격자 체력 100·50·25%로 고정) / 50%에서 먼저 궁극기 / 50%에서 쿨마다 액티브. 평타 피해와 능력 피해를 따로 셈, 힘·나약함 효과는 바닐라처럼 공격력에 반영(MockBukkit 보완), 치명타 끔 | 평타 강화(잃은 체력 비례 패시브, 액티브·궁극기의 평타 버프), 근접 흡혈, 근접에서의 궁극기·액티브 능력 피해 |

### 지표 (30초 싸움 기준)

- 궁극기는 40초에 한 번(싸움 중 게이지 + 재충전 잠금) → 30초에 ×0.75.
- **지속딜** = (30초 스킬 피해 + 궁극기 몫) / 30초. 스킬·궁극기 몫은 근접(평타와 함께) 장면이 더 크면 그쪽(다음 적중 강화·근접 강화 능력). **폭딜** = 아무 3초 동안 가장 큰 피해(액티브 한 번, 또는 궁극기 + 액티브).
- **평타 강화** = 근접 장면에서 키트가 자기 평타에 더한 피해: (체력 100·50·25% 평균 − 100%) + (액티브 − 50%) 는 12초마다, (궁극기 − 50%)는 궁극기 주기마다, 싸움의 70%를 근접에서 휘두른다고 봄. 지속딜에 더하고(능력 보정이 안 곱해짐), 궁극기·패시브 몫의 3초분은 폭딜에도 더함. **근접 흡혈** = 그 장면의 회복 − 결투의 회복, 같은 비율로 생존에 더함.
- **통제** = 강한 통제(기절·속박·이동 잠금·공중에 뜸) ×1 + 침묵 ×0.6 + 약한 통제(감속 비율·실명·점프 잠금) ×0.5 (초).
- **생존** = 자기 회복 + 보호막(흡수) + 시험타에서 막은 피해 + 늘어난 최대 체력 ×0.5 − 자해 ×0.5. **무적** = 시험타를 거의 안 받은 초.
- **이동** = 공격자가 능력으로 움직인 거리. **지원** = 아군 회복 + 보호막 + 막은 피해 + 버프 초 ×0.3.
- **광역** = 밀집 장면에서 둘째 이후 대상들이 받은 피해 합. **건물** = 타워 20초 피해(×objective).
- **웨이브** = 미니언 한 무리(체력 96)를 밀집 장면의 속도로 정리하는 초, **정글** = 곰인형 대장(체력 90)을 지속딜로 잡는 초(배율 없는 피해 ×objective).

### 점수

- **전투력** = 1v1 결투 모델에서 다른 모든 능력을 상대로 한 평균 승률. A가 B를 잡는 시간 = B의 체력(1레벨 20, 6레벨 26, 9레벨 28)을 A의 처음 3초(폭딜 속도) + 이후 지속딜로 깎는 시간, B의 회복·보호막과 막은 피해(A의 딜에 비례)를 빼고, B의 통제 비율(30초 중 통제 초, 최대 50%)만큼 A의 딜이 줄며, B가 사거리에서 앞서면 A는 그 차이를 초속 5블록(이동기로 줄임)으로 좁힌 뒤에야 칩니다(최대 3초). 승률 = T(B→A)² / (T(A→B)² + T(B→A)²).
- **공성 기여** = 건물 ×0.5 + 웨이브 속도 ×0.3 + 정글 속도 ×0.2 (풀 평균 = 1). **팀 기여** = 광역 ×0.3 + 통제 ×0.3 + 지원 ×0.4 (풀 평균 = 1, 각 지표 최대 3).
- **전체 점수** = 100 × (전투력/평균 ×0.55 + 공성 ×0.2 + 팀 ×0.25), 1·6·9레벨 평균. 목표: 모든 능력이 전체 점수 중앙값 ±12% 안, 역할 대역 안.

### 역할 대역 (`SiegeRoles`, 1 = 풀 평균)

| 역할 | 대역 |
|---|---|
| 탱커 | 생존+통제 ≥ 1.6, 지속딜 ≤ 1.0 |
| 전사 | 지속딜 0.45~1.6, 폭딜 ≥ 0.3 |
| 암살 | 폭딜 ≥ 1.0, 생존 ≤ 1.5 |
| 원거리 | 지속딜 ≥ 0.8, 사거리 ≥ 1.0, 생존 ≤ 1.5 |
| 마법 | 광역+통제 ≥ 0.9, 사거리 ≥ 0.7 |
| 서포터 | 지원+통제 ≥ 1.2, 지속딜 ≤ 1.0 |

### 보정 규칙

- 공성전 피해 = 전체 배율 **×0.65** × 능력별 보정(스킬/궁) × 레벨 보정(레벨마다 +7.5%, 9레벨 ×1.6) × 아이템·버프(`SiegeModifiers`). 건물·미니언·정글 몬스터에게는 능력 피해 × objective 보정만.
- `SiegeBalanceReport` 가 보정을 고릅니다: 1에서 시작해 전체 점수가 중앙값 ±6% 밖이면 스킬·궁 보정을 함께 옮기고(한 번에 ±15%), 역할의 지속딜·폭딜 대역으로 밀고, 공성 기여가 0.75~1.35 밖이면 objective 를 옮기기를 80번, 마지막에 0.05 단위로 내림. 보정 범위 0.3~1.8 (objective 0.4~2.5).
- 폭딜 상한(모델·랩 둘 다): 1레벨에서 어떤 시전도 3초 폭딜 8(체력의 40%) 이하, 9레벨(특성 포함)은 14(체력 28의 50%) 이하(테스트).
- 피해로 못 고치는 원인(긴 통제·무적·넉백·쿨타임)은 `SiegeTuning`(공성전 전용 수치, 아래 표)로 고칩니다.
- **평타 강화형**(지속딜의 25% 이상, 초당 0.4 이상이 자기 평타 강화): 스킬·궁 보정 최대 1. 보정은 능력 피해에만 곱해져 강함·약함의 원인(평타 버프)을 못 고치므로, 약하면 `SiegeTuning` 으로 고칩니다.
- **수동 결정**(`SiegeBalanceReport.PINNED`): 실전 피드백처럼 랩이 못 보는 근거로 정한 보정은 자동 산출이 덮어쓰지 않습니다(아래 표).
